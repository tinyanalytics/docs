To add TinyAnalytics to a **Vue** app, paste the tracking snippet into your `index.html` so it loads once for the whole app. Client-side navigation with Vue Router is tracked automatically, so you don't need to hook into the router.

## Before you start

- A TinyAnalytics site. If you don't have one yet, follow the [Quickstart](/tinyanalytics-quickstart).
- Your site's numeric **site ID**, from **Settings → Tracking** in your dashboard.

## Add the snippet to `index.html`

A Vue project created with Vite has a single `index.html` at the project root. Add the snippet inside its `<head>`:

```html index.html
<!doctype html>
<html lang="en">
  <head>
    <meta charset="UTF-8" />
    <title>My Vue App</title>
    <script defer src="https://dash.tinyanalytics.io/script.js"
      data-site-id="YOUR_SITE_ID"></script>
  </head>
  <body>
    <div id="app"></div>
    <script type="module" src="/src/main.js"></script>
  </body>
</html>
```

<Tip>
  Replace `YOUR_SITE_ID` with your real site ID, and copy the full snippet from **Settings → Tracking** if you've toggled any options.
</Tip>

## Client-side navigation is tracked automatically

Vue Router renders route changes on the client, and TinyAnalytics records each one as a new pageview by default (`data-track-spa`). You don't need to watch the route or call anything on navigation. See [Track single-page apps](/configure-tinyanalytics-tracking-script#track-single-page-apps) to change this behavior.

## Verify

Run or deploy your app, open it in a browser, then check **Realtime** in your dashboard for your visit. See [Verify your setup](/verify-tinyanalytics-installation) for the full check.

<Check>
  Your install is working when your own visit appears in **Realtime** in your dashboard.
</Check>
